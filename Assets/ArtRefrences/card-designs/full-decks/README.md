# Three complete Callbreak decks

Open **index.html** in a browser to select a theme, filter suits, inspect all 52 cards, and click a card for a larger view. Switch to **Suit sheets** to see the complete original PNG artwork.

The collection contains **156 card-face previews**: **52 in each theme**, saved as **12 PNG suit sheets**, each **1642 × 958**. Each sheet includes A, 2, 3, 4, 5, 6, 7 on the upper row and 8, 9, 10, J, Q, K on the lower row.

These are visual design references. Individual-card views are display regions of the source sheets, not separate production-ready card exports or editable vector components.

## Themes

- **Classic Crimson:** ivory faces, crimson/gold frames, black spades/clubs, red hearts/diamonds, crimson court costumes.
- **Himalayan Ivory:** light ivory, fine gold frames, faint mountain watermarks, black/red suits, ivory-and-gold court costumes.
- **Kathmandu Gold:** restored black/charcoal textured faces, gold frames, bright gold spades/clubs, and crimson hearts/diamonds with fine yellow-gold outlines around all ranks and suit symbols. Court costumes retain charcoal, crimson, and gold details. This is the latest requested version and supersedes the V3 ivory faces.

All three decks include illustrated double-ended Jacks, Queens, and Kings with Nepali-inspired geometric costume details.

## Files and provenance

- `manifest.json`: 12 sheets and all 156 unique theme/suit/rank entries, with approximate display regions for the gallery.
- `generation-prompts.md`: original built-in image-editor prompts and corrections.
- `kathmandu-gold-black-prompts.md`: latest exact prompts restoring all 52 Kathmandu Gold faces to black with outlined red suits.
- `archive/kathmandu-gold-ivory/`: preserved previous ivory-faced Kathmandu Gold sheets.
- Original approved four-ace images remain in the parent folder.

No jokers or card backs are added; this request covers all 52 face designs for each deck. Existing card-back concepts remain in the project’s card-collection screen.
